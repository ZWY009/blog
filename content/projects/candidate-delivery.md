## 场景

高端求职服务里，给一个候选人找岗不是"搜出来发过去"就完了：

- 岗位要匹配这个人的画像（学历、方向、城市、薪资区间）
- **链接必须是活的**——招聘网站岗位下架是常事，交过去的链接打不开，整个交付就废了
- 交付物要能直接用：Excel + 在线表格，字段口径还得一致

## 最核心的一环：深链核验

这件事看起来是"搜索"，实际上难点在**验证**。

每条岗位链接在交付前都要实际请求一遍，判断是否还在招、是否被重定向到了首页、是否只剩一个空壳页面。链接失效了就换一个，不能带着死链交付。

这一步把一个"看起来做完了"的任务变成了**可证伪的**——任何一个链接打不开，都能当场指出来。

## 交付形态

结果落成 Excel（给候选人自己看）和钉钉在线表格（团队协作），两边字段口径必须一致。所以数据只有一份真源，两种导出，而不是分别手工维护两份。

## 技术栈

Python 做采集与核验流水线，钉钉开放平台 API 做在线表格交付，HTTP 探测做链接有效性判断。

## 学到的东西

**自动化的价值不只是快，是"可核验"。** 人工做一百条链接，总会有几条忘了点开；机器做一百条，一百条都点过。
